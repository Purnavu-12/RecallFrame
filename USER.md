# Primary user

The initial user is one person running RecallFrame on their own computer. They import educational videos, search what was said, ask source-grounded questions, save useful ideas, and return to the exact playback moment. They want local ownership and clear notice before any external inference.

## Experience needs

- Keep the source, transcript, and answer visible in one workspace.
- Make timestamps a direct path to playback.
- Explain processing stages and failures in plain language.
- Offer keyboard-accessible controls and a mobile layout that preserves playback and citation navigation.
