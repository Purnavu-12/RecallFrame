# Product experience

## Workspace

The product has a persistent navigation rail and a source workspace with media and timestamped transcript in the main column and Ask this video/evidence in the secondary panel. The reference screenshot informed the information hierarchy. The visual system uses dark zinc, fine borders, compact density, Inter, IBM Plex Mono timestamps, and violet for selected/focused actions.

## Interaction principles

- Click a citation, chapter, search result, or saved insight to navigate to a source moment.
- Keep evidence text and timestamps adjacent to generated claims.
- Show processing state and error state without presenting mock analysis as completed work.
- Collapse secondary panels on narrow screens and keep media/citation navigation available.
